Detailed Description

Orchestrateur principal du jeu Laying Grass.

La classe instancie la grille, charge les tuiles, gère la boucle des tours et pilote le renderer Raylib pour l'affichage/les interactions.

Cette méthode s'occupe d'initialiser le renderer, d'enchaîner les tours, puis de calculer/afficher les scores finaux.
