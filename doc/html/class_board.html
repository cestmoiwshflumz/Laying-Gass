Detailed Description

Représente la grille carrée sur laquelle les joueurs placent leurs tuiles.

La classe s'occupe de vérifier les collisions, l'adjacence aux territoires, la collecte des bonus et le calcul des zones finales.

Pose une tuile sur la grille après vérification locale.

Cette méthode doit être appelée après canPlaceTile. Elle parcourt la matrice tileShape et copie le symbole du joueur dans chacune des cases cibles.

tileShapeMatrice binaire représentant la forme normalisée.

Returns
