\doxysubsection{Detailed Description}
Représente la grille carrée sur laquelle les joueurs placent leurs tuiles. 

La classe s\textquotesingle{}occupe de vérifier les collisions, l\textquotesingle{}adjacence aux territoires, la collecte des bonus et le calcul des zones finales.
